# Item 2: Trial Data Feasibility and Translation Validation

This folder contains the reviewer-facing PDF for SemEval revision item 2.

The current version refocuses the reviewer response on the main multilingual feasibility issue identified during preparation:
target-side translation collapse, where two distinct English phrases translate to exactly the same Spanish or Basque text.

The PDF `2.Pilot_Trial_Data_Demonstration.pdf` now summarizes:

- the full grouped English PhrasIS-derived inventory;
- the definition of translation collapse;
- the 500-pair stratified feasibility experiment;
- `gpt-5.4` and `gpt-5.6-sol` Spanish/Basque translation results;
- cross-model recovery of collapsed cases;
- projected impact on the `EQUIVALENCE` class;
- the resulting validation protocol for trial and final data.
